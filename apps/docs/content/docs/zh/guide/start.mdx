把模型接到屏幕上需要三样东西：一份教模型写标记的系统提示词，一个把回复画出来的组件，以及界面用来访问你产品的几个回调。

## 安装 [#install]

安装你所用框架的渲染器、core，以及渲染器所依赖的 UI SDK 包。


```bash tab="React"
npm install @open-intelligent-ui/react @open-intelligent-ui/core @ui-sdk/react @ui-sdk/core
```

```bash tab="Vue"
npm install @open-intelligent-ui/vue @open-intelligent-ui/core @ui-sdk/vue @ui-sdk/core
```

```bash tab="Svelte"
npm install @open-intelligent-ui/svelte @open-intelligent-ui/core @ui-sdk/svelte @ui-sdk/core
```

```bash tab="Solid"
npm install @open-intelligent-ui/solid @open-intelligent-ui/core @ui-sdk/solid @ui-sdk/core solid-js @solidjs/web
```

```bash tab="不用框架"
npm install @open-intelligent-ui/web @open-intelligent-ui/core @ui-sdk/web @ui-sdk/core
```


| 包 | 要求 |
| --- | --- |
| `@open-intelligent-ui/react` | React 19 或更高。入口带有 `"use client"` 标记 |
| `@open-intelligent-ui/vue` | Vue 3.5 或更高 |
| `@open-intelligent-ui/svelte` | Svelte 5.33 或更高，以及装了 Svelte 插件的打包工具 |
| `@open-intelligent-ui/solid` | Solid 2 |
| `@open-intelligent-ui/web` | Vite 之类的打包工具。提供 `<intelligent-ui>` 元素和 `mount()` |

所有包都是 ESM，带类型声明。不带作用域的 `open-intelligent-ui` 重新导出 `@open-intelligent-ui/core`。

## 生成系统提示词 [#build-the-system-prompt]

在服务端，也就是你调用模型的地方：

```ts
import { buildSystemPrompt } from "@open-intelligent-ui/core/prompt"

const system = buildSystemPrompt({
  instructions: "You are the support desk assistant for Acme.",
  tools: [
    {
      name: "listTickets",
      kind: "read",
      description: "Tickets in the support queue.",
      input: { status: "open | pending | solved | all" },
      output: "[{ id, subject, status, priority, assignee }]",
    },
    { name: "updateTicket", kind: "write", description: "Change a ticket.", input: { id: "string", status: "?" } },
  ],
})
```

把 `system` 作为任意聊天 API 的系统消息发出去。提示词里有语言、基础元素和预设组件、UI SDK 组件、动效、写界面的准则、设计和你的工具。默认大约 34,000 个字符，[API 参考](/zh/reference/api#buildsystemprompt)列出了能缩短它的选项。

## 渲染回复 [#draw-the-reply]

每收到一段，就把到目前为止的回复传进去。每个助手回合渲染一个 `<IntelligentUI>`，它们各有各的状态。


```tsx tab="React"
import { IntelligentUI } from "@open-intelligent-ui/react"
import "@open-intelligent-ui/react/styles.css"

function Reply({ text, streaming }: { text: string; streaming: boolean }) {
  return (
    <IntelligentUI
      source={text}
      streaming={streaming}
      tools={{ listTickets, updateTicket }}
      onAction={(action) => {
        if (action.type === "send") askModel(action.text, action.data, action.state)
        return undefined
      }}
      onWarning={(message) => console.warn(message)}
    />
  )
}
```

```vue tab="Vue"
<script setup lang="ts">
import { IntelligentUI } from "@open-intelligent-ui/vue"
import "@open-intelligent-ui/vue/styles.css"

defineProps<{ text: string; streaming: boolean }>()

function onAction(action) {
  if (action.type === "send") askModel(action.text, action.data, action.state)
}
</script>

<template>
  <!-- 回调是接收函数的 props：写 :on-action，不是 @action。 -->
  <IntelligentUI
    :source="text"
    :streaming="streaming"
    :tools="{ listTickets, updateTicket }"
    :on-action="onAction"
    :on-warning="(message) => console.warn(message)"
  />
</template>
```

```svelte tab="Svelte"
<script lang="ts">
  import { IntelligentUI } from "@open-intelligent-ui/svelte"
  import "@open-intelligent-ui/svelte/styles.css"

  let { text, streaming }: { text: string; streaming: boolean } = $props()

  function onAction(action) {
    if (action.type === "send") askModel(action.text, action.data, action.state)
  }
</script>

<IntelligentUI source={text} {streaming} tools={{ listTickets, updateTicket }} {onAction} />
```

```tsx tab="Solid"
import { IntelligentUI } from "@open-intelligent-ui/solid"
import "@open-intelligent-ui/solid/styles.css"

function Reply(props: { text: string; streaming: boolean }) {
  return (
    <IntelligentUI
      source={props.text}
      streaming={props.streaming}
      tools={{ listTickets, updateTicket }}
      onAction={(action) => {
        if (action.type === "send") askModel(action.text, action.data, action.state)
        return undefined
      }}
    />
  )
}
```

```html tab="不用框架"
<intelligent-ui id="reply"></intelligent-ui>

<script type="module">
  import "@open-intelligent-ui/web/define"
  import "@open-intelligent-ui/web/styles.css"

  const reply = document.querySelector("#reply")
  reply.tools = { listTickets, updateTicket }
  reply.addEventListener("action", (event) => {
    if (event.detail.type === "send") askModel(event.detail.text, event.detail.data, event.detail.state)
  })
  reply.streaming = true
  reply.source = textSoFar
</script>
```


- **给它一个宽度。** 这块界面是一个尺寸容器，会按拿到的空间自己排版，从手机的一栏到整页都可以。
- **UI SDK 组件在第一次用到时才加载。** 如果不想有这段等待，尽早调用 `preloadUiSdk()`，或者 `preloadUiSdk("Tabs", "Dialog")`。
- **服务端渲染。** 对服务端渲染结果做水合还没有测试过。请在浏览器里渲染：Nuxt 用 `<ClientOnly>`，SolidStart 用 `clientOnly`，Next.js 里因为有函数类型的 props，要放在客户端组件中。
- **回复外面包了一层代码围栏。** 有些模型即使被告知不要，还是会把回复包在代码围栏里。渲染前把它去掉；检查器会把这种情况报告为 `fenced`。

## 检查回复 [#check-the-reply]

一份回复写完、存下来之前，先检查它，有错就让模型改。这个循环跑在服务端：

```ts
import { checkMarkup, repairMessage } from "@open-intelligent-ui/core/check"

const tools = ["listTickets", "updateTicket"]
let reply = await model(messages)
let result = checkMarkup(reply, { tools })
for (let round = 0; !result.ok && round < 2; round++) {
  messages.push({ role: "assistant", content: reply }, { role: "user", content: repairMessage(result) })
  reply = await model(messages)
  result = checkMarkup(reply, { tools })
}
```

[保证输出正确](/zh/guide/correctness)说明了它能查出什么，以及流式输出时怎么用。

## 把回合接回来 [#take-the-turn-back]

用户做出决定时，标记会调用 `send("Book the Kyoto option", { id })`。你的 `onAction` 会收到这句话、附带的数据和这块界面的状态。把它作为一条用户消息加进对话，再问一次模型：

```ts
function askModel(text: string, data: unknown, state: Record<string, unknown>) {
  messages.push({
    role: "user",
    content: `${text}\n\n<context>${JSON.stringify({ data, state })}</context>`,
  })
  startTurn(messages)
}
```
